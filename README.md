## // selected work

- **[deepseek-chat-navigator](https://github.com/widechaos/deepseek-chat-navigator)** — a browser userscript that turns long DeepSeek conversations into a question-and-answer outline with one-click navigation.
- **[Bulletin](https://github.com/widechaos/Bulletin)** — a Python + Qt desktop news overlay: live headlines, a transparent window, and click-through interaction.
- **[obsidian-cinematic-ui](https://github.com/widechaos/obsidian-cinematic-ui)** — a cinematic CSS motion layer for Obsidian: glass callouts, breathing alerts, image reveals.
- **[Heartiger](https://github.com/widechaos/Heartiger)** — designing an agent-driven personal life OS: lightweight journaling, intelligent organization, and a growing second brain.
- **[widechaos-blog](https://github.com/widechaos/widechaos-blog)** — thinking out loud, in the open → [widechaos.cn](https://widechaos.cn).
